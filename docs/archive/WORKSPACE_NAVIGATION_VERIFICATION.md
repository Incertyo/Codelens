The 309 entries form a broad curated DSA catalog, not a claim to enumerate every algorithm in every field. Catalog-only entries provide a description and a blank implementation action; they do not pretend to have runnable code. All seventeen linked samples have actual authored Python/JavaScript implementations. Educational execution/snapshot limits and the existing client-only execution boundary are unchanged.

Opening and run loaders have distinct markers from Next's route fallback; streaming can briefly retain hidden fallback markup. No artificial minimum loading duration is imposed. Preparation percentage is not presented as execution completion. Scrubbing measurements are local headless Chromium results and include refresh timestamp quantization; they are not guarantees for every device.

Reproduce with `npm run lint`, `npm run typecheck`, `npm test`, `npm run test:e2e`, and `npm run build`. On a production server at port 3001, run `node scripts/audit-browser.mjs`, `node scripts/measure-scrubbing.mjs`, and `node scripts/preview-workspace.mjs`. Reports/screenshots are in ignored `artifacts/`. The catalog, interaction and loading choices are recorded in [DECISIONS.md](DECISIONS.md).
